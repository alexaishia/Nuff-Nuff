# Infinity Lock

A tiny interactive Gradio game.

## Deploy on Hugging Face Spaces

1. Create a new **Gradio** Space.
2. Upload everything in this folder to the Space.
3. Wait for the build to finish.
4. Open the Space URL and share it.

The app uses `nyx.png` and `dusty.png` from the repository root.
